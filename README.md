**Movie Night Picker**

Pick a color based on how you feel today, play two guessing rounds, then pick a movie to watch. You can read the movie intro and listen to a soundtrack inspired by the movie.

**How to Play**

1. Pick a color based on how you feel today
2. Round 1: guess which movie is rated higher on IMDb
3. Round 2: guess which movie is older
4. Pick the movie you want to watch
5. Read the movie intro and listen to the soundtrack
